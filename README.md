# Nyumba — Multipage Website (Final Project)

**Project summary**
Nyumba is an intelligent rental platform focused on first-time renters, property managers, and landlords. This repo contains a static 3-page site (Home / About / Contact) demonstrating HTML5, CSS3, and JavaScript interactivity. The site is responsive and ready to deploy to GitHub Pages, Netlify, or Vercel.
